## StarterProperty

One page property of the `properties` schema.

```ts
export type StarterProperty = {
    id: string;
    type: StarterPropertyType;
    name?: string;
    icon?: string;
    options?: readonly StarterPropertyOption[];
    hidden?: boolean;
    removable?: boolean;
    placeholder?: string;
};
```

- `id`: The key of its value in the document's `properties`.
- `name`: What the page shows (default `id`).
- `icon`: A short icon (an emoji or a character) before the name.
- `options`: A `select` or `multi-select` property's options.
- `hidden`: Shown only once a user adds it (default `false`: shown).
- `removable`: Users may hide it (default `true`, when the editor's `editableProperties` allows it).
- `placeholder`: The field's placeholder (default the words' `empty`).

## StarterTheme

The look of the starter editor, mapped to CSS variables on its root.

```ts
export type StarterTheme = {
    colors?: {
        light?: StarterColors;
        dark?: StarterColors;
    };
    colorScheme?: 'light' | 'dark' | 'auto';
    fonts?: {
        body?: string;
        mono?: string;
        title?: string;
    };
    radius?: string | number;
    spacing?: string | number;
    maxWidth?: string | number;
    coverHeight?: string | number;
    variables?: Record<`--${string}`, string>;
};
```

- `colors`: Light colours, and the dark ones (used under `colorScheme` `dark`, or `auto` in a dark system).
- `colorScheme`: `light` (default), `dark`, or `auto` (the system's).
- `radius`: `--edytor-starter-radius`: the page parts' corners (a CSS length or a number of px).
- `spacing`: `--edytor-starter-gutter`: the page's side padding (a CSS length or a number of px).
- `maxWidth`: `--edytor-starter-max-width`: the column of text (a CSS length or a number of px).
- `coverHeight`: `--edytor-starter-cover-height` (a CSS length or a number of px).
- `variables`: Any other CSS variable, by its full name (`--edytor-color-red`).
