This page renders an editor, adds one plugin to it and reads the document as it changes. It assumes you have [installed](/docs/getting-started) `edytor`.

## Render an editor

```svelte title="src/routes/+page.svelte" check
<script lang="ts">
	import { Edytor } from 'edytor';
</script>

<Edytor />
```

You see one empty paragraph: an empty document always starts with one block of the default type. `<Edytor>` includes the rich text and suggestions plugins, so this is already a rich text editor with its keyboard shortcuts (<kbd>Mod</kbd>+<kbd>B</kbd>, <kbd>Mod</kbd>+<kbd>Alt</kbd>+<kbd>1</kbd>, …).

`<Edytor>` renders on the server and hydrates in the browser, so it works in any route. An editor connected to a room renders its content once the room answers; see [SvelteKit](/docs/getting-started/sveltekit).

## Add a plugin

Every other block kind comes from a plugin. Import its factory from `edytor` and pass it in `plugins`. Here, code blocks, with a first document passed as `value`:

```svelte title="src/lib/Editor.svelte" check
<script lang="ts">
	import { Edytor, createCodePlugin, type JSONDoc } from 'edytor';

	const value: JSONDoc = {
		children: [
			{ type: 'heading', data: { level: 'h1' }, content: [{ text: 'Notes' }] },
			{
				type: 'code',
				data: { language: 'javascript' },
				children: [{ type: 'codeLine', content: [{ text: 'console.log("hello");' }] }]
			}
		]
	};
</script>

<Edytor {value} plugins={[createCodePlugin()]} />
```

The code block highlights its lines, and typing ```` ``` ```` on an empty line, or <kbd>Mod</kbd>+<kbd>Alt</kbd>+<kbd>8</kbd>, makes a new one. `value` is a `JSONDoc`, a tree of blocks ([Document model](/docs/concepts/document-model)). The editor reads it once, when it mounts.

[Plugins](/docs/plugins) lists the others: tables, columns, images and media, mentions, comments, markdown shortcuts…

## Read the document

`onChange` receives the whole document after every change: a local edit, a remote edit or an undo. Keep it in a `$state` and use it in your markup:

```svelte title="src/lib/EditorWithPreview.svelte" check
<script lang="ts">
	import { Edytor, createCodePlugin, type JSONDoc } from 'edytor';

	let value = $state<JSONDoc>({
		children: [{ type: 'heading', data: { level: 'h1' }, content: [{ text: 'Notes' }] }]
	});
	// The first heading's text: its content is text runs (and inline blocks, which have none).
	const heading = $derived(value.children?.find((block) => block.type === 'heading'));
	const title = $derived(
		heading?.content?.map((run) => ('text' in run ? run.text : '')).join('') || 'Untitled'
	);
</script>

<Edytor {value} plugins={[createCodePlugin()]} onChange={(next) => (value = next)} />

<p>{title}: {value.children?.length ?? 0} blocks</p>
<pre>{JSON.stringify(value, null, 2)}</pre>
```

The document you receive is the same shape `value` takes, so you can store it and open it again as `value`. The editor reads `value` only when it mounts: assigning it afterwards does not replace the content, and `value` is not bindable (write `onChange`, not `bind:value`). To change the content from code, use [commands](/docs/editor/commands).

## Style it

Import the Notion theme and put the editor in an element with its class:

```svelte title="src/lib/StyledEditor.svelte" check
<script lang="ts">
	import { Edytor } from 'edytor';
	import 'edytor/themes/notion.css';
</script>

<div class="edytor-notion">
	<Edytor />
</div>
```

Or style it yourself: every block carries `data-edytor-*` attributes. See [Styling](/docs/customization/styling).

## Menus and handles

The editor shows no slash menu, toolbar or block handle until you give their plugins a snippet that draws them: see [Menus and handles](/docs/customization/menus). To start from the demo's Notion-style ones, copy them from the repository: see [Ready-made menus](/docs/customization/ready-made-menus).
