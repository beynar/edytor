## 3. Storage schema (v13)

- Root: `doc.getMap('content')` → `YBlock = Y.Map` with keys `type`(`'root'`), `id`, `data`, `children`, `content` (`block.svelte.ts:428-434`).
- Block: `new Y.Map({type, id, data, children: Y.Array<YBlock>, content: Y.Array<YMap|YText>})` (`block.svelte.ts:436-444`).
- Inline block: `Y.Map` with `type`, `data` (`inlineBlock.svelte.ts:62-72`).
- Text: `Y.Text` with per-text `id` via `setAttribute('id')` (`text.svelte.ts:115-116`).
- Bootstrap sentinel: `doc.getText('INITIALIZED')` — doc is "already initialized" iff its content equals `'INITIALIZED'` (`edytor.svelte.ts:340-363`).

## 4. Sequential operation contracts

All ops bound via `batch()` wrappers. **Block batch** (`block.utils.ts:69-106`): readonly → `undefined`; first plugin `onBeforeOperation` returning a payload wins (normalized payload used); runs inside `edytor.transact` (origin = `TRANSACTION` instance); then all `onAfterOperation` hooks fire with the **original** payload; returns op result. **Text batch** (`text.utils.ts:36-70`): same but `this: Text`, no readonly guard (relies on callers/input gating). History: one undo step per `edytor.transact` (UndoManager tracks `{transaction, null}` origins; `null` also captures bare `doc.transact` calls such as the inner transaction inside `insertText`).

**Identity note (critical for U01/U03):** every structural move/reparent/split/merge recreates Yjs objects from serialized `block.value` JSON — Yjs identity (and item ids) are **not** preserved today. `id` fields are regenerated via `id('b')`/`id('t')` in new wrappers, but `value` carries `id` through JSON so the JSON-level `id` survives the round-trip in some paths — verify per op below.

## 5. Bootstrap, onChange, readonly, providers

- **Bootstrap** (`edytor.svelte.ts:335-387`): `sync(value)` is one-shot (`synced` flag). Reads `doc.getText('INITIALIZED')`; if sentinel present → wrap existing `yRootBlock` (hydrated path); else seed `children` JSON into a new root block. Non-readonly then writes the sentinel (delete+insert). Registers `doc.on('update')` handler.
- **`onChange` semantics**: fires on **every** `doc` update — local ops and remote provider-applied updates alike. Payload = full serialized `this.value` (`{type:'root', children}`). Calls `this.onChange?.(value)` then every `plugin.onChange?.(value)`; also schedules stale-placeholder cleanup on `tick()`.
- **Readonly** (`components/ReadonlyEditor.svelte`, `readonlyElements.svelte.ts`): separate `Edytor` with `{readonly:true, value}`; renders `ReadonlyBlock`/`ReadonlyText`/`ReadonlyInlineBlock` proxies over the generated JSON tree — no live Yjs observers, block `batch` no-ops, sentinel not written.
- **Provider lifecycle** (`collaboration/providers.ts`, `localProvider.ts`, `components/Edytor.svelte:169-190`): `EdytorSync` receives `{doc, awareness, synced}`; `synced(provider?)` triggers `edytor.sync(initialValue)` — hydration happens **after** provider data is applied, so a persisted/synced doc wins over `value`. Cleanup: `sync()` may return `() => void | Promise<void>`; Edytor.svelte invokes it on teardown and rethrows async rejection. `IndexeddbPersistence` (localProvider fork): `doc.on('update')` → append update to `updates` IDB store + broadcast `messageSync` via BroadcastChannel; `fetchUpdates` applies stored updates inside `Y.transact(doc,…,idbPersistence)`; `connectBc` emits sync step1/step2 + awareness query/state, sets `synced=true`, emits `'synced'`; `storeState` compacts to a single `encodeStateAsUpdate` snapshot when ≥500 updates; `destroy()` unsubscribes bc, removes listeners, broadcasts awareness-removal, closes DB (deletes nothing — `clearDocument` is separate).

## 7. Top v14 coupling risks

1. `src/lib/text/deltas.ts` — raw `_start`/`right`/`content`/`deleted` item-list walk + `Content*` constructor identity. Rewrite against v14 public delta API or re-vendor `toDelta` semantics.

4. Identity preservation: current ops clone-via-JSON on every move/nest/merge/split — v14 identity work must replace this wholesale, including `moveBlocksTo` grouped drag (multi-undo-step today).
5. `localProvider.ts` re-implements y-indexeddb + BC sync against lib0/y-protocols internals — verify lib0 API drift under v14 bump.
6. `INITIALIZED` sentinel doc-level `Y.Text` + `doc.getMap('content')` root schema — must be preserved/migrated for stored docs.
