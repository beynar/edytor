## fromHTML

HTML as a document, the paste's reading (`flow.html.*`): only the kinds,
marks and atoms of `kinds` survive (an unknown element is its text, a
`script` or `style` nothing), every value through its record's `parse`
hook (a link's href through the link sanitizer: `javascript:` drops the
link, an image's source through the image's), and nothing executes: the
parser only parses, no attribute is copied (`onerror`, `style`).

```ts
import { DOMParser } from 'linkedom'; // on a server; the browser has its own
import { fromHTML } from 'edytor/export';
const value = fromHTML(html, { DOMParser });
```

```ts
declare const fromHTML: (html: string, options?: ImportOptions) => JSONDoc;
```

## MarkdownContext

What a kind's `markdown` form is given beside its block, content and children.

```ts
export type MarkdownContext = {
    index: number;
    indent: (text: string, prefix: string) => string;
    inline: (content: JSONBlock['content']) => string;
};
```

- `index`: The block's position in its run of same-kind siblings, from 1 (a numbered item's number).
- `indent`: Every line of `text` prefixed with `prefix` (`'  '` under a list item, `'> '` in a quote).
- `inline`: Rich text as inline markdown, by the marks' and atoms' forms (a table cell's).

## textToBlocks

`text` as blocks (see the module comment).


## TextToBlocksOptions

```ts
export type TextToBlocksOptions = {
    markdown?: boolean;
    type?: string;
    streaming?: boolean;
};
```

- `markdown`: Read markdown (default `true`); `false` keeps every character as text.
- `type`: The kind of a paragraph (default `paragraph`).
- `streaming`: The text is still arriving (default `false`): hold back an unfinished last line's block marker or unclosed inline marker, and a table header row without its separator yet, so a streamed preview never shows raw markdown that the next chunk turns into a kind or a mark.

## toHTML

A document (or blocks) as HTML: each block by its kind's `html` form, a
run of list items in their list's element, text by its marks' elements.
Values are escaped and links through the link sanitizer; ids and empty
data are never written.

```ts
import { toHTML } from 'edytor/export';
const html = toHTML(value);
```

```ts
declare const toHTML: (doc: JSONDoc | readonly JSONBlock[], options?: ExportOptions) => string;
```

## toMarkdown

A document (or blocks) as Markdown (CommonMark with GFM tables, task
lists and strikethrough): each block by its kind's `markdown` form (else
its `plain` form), marks by theirs, atoms by theirs (else their `plain`
form). A toggle is a `<details>` disclosure, a callout a `> [!NOTE]`
alert; `textToBlocks` reads both back.

```ts
declare const toMarkdown: (doc: JSONDoc | readonly JSONBlock[], options?: ExportOptions) => string;
```
