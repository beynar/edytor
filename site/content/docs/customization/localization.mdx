Every word the editor shows or says comes from a dictionary of labels: the menus, the toolbar, the handles' names, the empty image and media panels, the code header, the find bar, the suggestion bar, the page, table of contents and page link blocks, the equations, the placeholders and what screen readers hear. English is the default. To show another language, pass each plugin its `labels`, and the view its own:

| Words | Where to pass them | Section of `Labels` |
| --- | --- | --- |
| Kinds and marks (menu rows, toolbar buttons, handle names), the to-do checkbox | `createRichTextPlugin({ labels, keywords })` | `richText` |
| Placeholders | `createRichTextPlaceholder(labels)`, as `<Edytor placeholder>` | `richText` (`placeholders`) |
| The selection toolbar and the link card | `createToolbarPlugin({ labels })` | `toolbar` |
| The slash and `+` menus, their section headings | `createSlashMenuPlugin({ labels })` | `slashMenu` |
| The block menu, its Turn into and Color flyouts | `createBlockMenuPlugin({ labels })` | `blockMenu` |
| The `+` and grip of each block | `blockHandles={{ labels }}` or `createBlockHandlesPlugin({ labels })` | `blockHandles` |
| The image block and its chrome | `createImagePlugin({ labels })` | `image` |
| The embed, bookmark, file, video and audio blocks, the pasted-link menu | `createEmbedPlugin`, `createBookmarkPlugin`, `createFilePlugin`, `createVideoPlugin`, `createAudioPlugin` (`{ labels }`) | `media` |
| The code block's header and its languages | `createCodePlugin({ labels })` | `code` |
| The find bar | `createFindPlugin({ labels })` | `find` |
| The suggestion bar | `createSuggestionsPlugin({ labels })` | `suggestions` |
| The layout commands and the column resize bands | `createColumnsPlugin({ labels })` | `columns` |
| The page block and its "Page" command | `createPagePlugin({ labels, keywords })` | `page` |
| The table of contents block and its preset | `createTocPlugin({ labels, keywords })` | `toc` |
| The `[[` page link menu and atom | `createPageLinkPlugin({ labels })` | `pageLink` |
| The block and inline equations and their editor | `createEquationPlugin({ labels, keywords })` | `equation` |
| Block move and delete announcements, a suggestion's default name | `<Edytor labels>` | `editor` |

`labels` takes any entries of its section: the ones you leave out stay English, and so does an entry of a nested group (`kinds`, `placeholders`, `groups`, `colors`, a media kind) you leave out. A label that says something about a value is a function of it, so each language orders and inflects its own words: `movedUp: (what) => ...`, `columns: (count) => ...`, `fileSize: (bytes) => ...`.

```ts title="hints.ts" check
import { createRichTextPlaceholder, createToolbarPlugin } from 'edytor';

// One word changed: the rest stays English.
export const toolbar = createToolbarPlugin({ labels: { link: 'URL' } });
export const placeholder = createRichTextPlaceholder({
	placeholders: { empty: 'Write, or press / for blocks' }
});
```

```ts title="src/lib/fr.ts" check
		value /= 1024;
		unit++;
```

```svelte title="src/lib/Editor.svelte" check
		createRichTextPlugin({ labels: fr.richText, keywords: frKeywords }),
		createSlashMenuPlugin({ labels: fr.slashMenu }),
		createToolbarPlugin({ labels: fr.toolbar }),
		createBlockMenuPlugin({ labels: fr.blockMenu }),
		createImagePlugin({ labels: fr.image }),
		createVideoPlugin({ labels: fr.media }),
		createCodePlugin({ labels: fr.code }),
		createFindPlugin({ labels: fr.find }),
		createSuggestionsPlugin({ labels: fr.suggestions }),
		createColumnsPlugin({ labels: fr.columns }),
		createPagePlugin({ labels: fr.page, keywords: frKeywords }),
		createTocPlugin({ labels: fr.toc, keywords: frKeywords })

<Edytor
	{plugins}
	labels={fr.editor}
	blockHandles={{ labels: fr.blockHandles }}
	placeholder={createRichTextPlaceholder(fr.richText)}
	aria-label="Corps de la page"
/>
```

The view's own accessible name is yours to give (`aria-label`, `aria-labelledby`): the editor has none of its own.

## Slash keywords

The slash menu finds a kind by its label and by its keywords. A translated label is found as it is: `/titre` finds "Titre 1". The English keywords stay unless you replace them: `keywords` takes, by command id, the keywords that replace a preset's own (list the English ones in it to keep them). The rich text plugin's command ids are `block.paragraph`, `block.heading1` to `block.heading3`, `block.toggle-heading1` to `block.toggle-heading3`, `block.bulleted-list-item`, `block.numbered-list-item`, `block.todo-item`, `block.toggle`, `block.callout`, `block.quote` and `block.divider`. The image, code, media, columns, page and table of contents plugins take the same `keywords` option for theirs (`block.image`, `block.code`, `block.embed`, `block.bookmark`, `block.file`, `block.video`, `block.audio`, `columns.2` to `columns.5`, `page.new`, `block.toc`).

## Section headings and colors

A preset's `group` (`Basic blocks`, `Advanced blocks`, `Media`, `Layout`, or one of your own) is a key: the slash menu shows it through its `groups` labels, and a group with no entry as it is written. Write your own groups in your language, or map them in `groups`. The same holds for the palettes: `TOOLBAR_COLORS` names each toolbar color (`Red`), and the toolbar shows it through its `colors`; the block menu's Color flyout names each block color by its `BLOCK_COLORS` name (`red`, and `default` for none) through its own `colors`, each row said by `colorText` or `colorBackground` ("Red text", "Red background").

Code languages are named by the language list (`CODE_LANGUAGES`, or your `languages`); the code labels' `languages` replaces a label by language id (`{ plaintext: 'Texte brut' }`).

## Custom markup

A custom `menu`, `item`, `toolbar` or `bar` snippet renders your words, but its controller carries the plugin's labels (`controller.labels`, `find.labels`), so your markup can reuse them. A custom block handle receives the block's kind as `label`, read from the kind's translated preset.

## What is not localized

- **Your document.** Labels translate the chrome, never the content: a document keeps the text people typed.
- **Your own kinds, marks and commands.** Their `label`, `keywords` and `group` are what you write in their records: write them in your language, or build them from your own dictionary. So are your own [triggers](/docs/plugins/input-rules#triggers): their `name`, `empty` and `searching` texts.
- **Key names on a Mac.** The shortcuts the menus show use the Mac's symbols (⌘, ⇧, ↵) there; elsewhere the `ctrl`, `shift` and key-name labels.
- **Number and date formats** beyond what a label function formats: `fileSize` and the find bar's `count` are functions, so use `Intl.NumberFormat` there if you need it.
- **Right-to-left chrome.** Blocks take their text's direction, but the menus and toolbars are laid out left to right.
