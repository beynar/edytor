The package draws no menu, toolbar, handle or panel: each is a snippet you pass its plugin ([Menus and handles](/docs/customization/menus)). `edytor/starter` draws all of them the Notion way, and exports each bundled plugin given that markup, so your own `<Edytor>` lists them as they are. The [starter editor](/docs/starter) is the same chrome with the page around the blocks, in one component.

## What it exports

- `chrome`: one snippet per surface (the slash menu, the toolbar and its link card, the block handles and the block menu, the code header and its language list, the table's grips and menus, the image toolbar, the empty media panel, the callout icon picker, the comment cards, the find bar…), to pass a factory yourself.
- Each package factory given those snippets: `slashMenuPlugin` is `createSlashMenuPlugin` with the starter's `menu`, and `slashMenu(options)` takes the factory's other options. The same for `toolbar`, `blockMenu`, `blockHandles`, `code`, `table`, `equation`, `image`, `embed`, `bookmark`, `calloutIcons`, `find`, `marquee`, `mention`, `pageLink`, `comments`, `file`, `video` and `audio`; `imageToolbarPlugin`, `mediaEmptyPlugin` and `suggestionBarPlugin` are ready as they are.
- `HistoryPanel`: the [version history panel](/docs/server/history-panel).
- `words` and `setWords`: the chrome's words ([Localization](/docs/customization/localization)).

Only an app that imports `edytor/starter` ships it: `<Edytor />` from `edytor` does not grow.

## Pass its plugins

```svelte title="src/lib/NotionEditor.svelte" check
<script lang="ts">
	import { Edytor } from 'edytor';
	import 'edytor/themes/notion.css';
	import {
		blockHandlesPlugin,
		blockMenuPlugin,
		calloutIconsPlugin,
		codePlugin,
		imageToolbarPlugin,
		mediaEmptyPlugin,
		slashMenuPlugin,
		toolbarPlugin
	} from 'edytor/starter';

	const plugins = [
		slashMenuPlugin,
		toolbarPlugin,
		blockHandlesPlugin,
		blockMenuPlugin,
		codePlugin,
		imageToolbarPlugin,
		mediaEmptyPlugin,
		calloutIconsPlugin
	];
</script>

<div class="edytor-notion">
	<Edytor {plugins} />
</div>
```

That is the editor above: a `/` menu, a toolbar over a selection, a `+` and a grip beside each block with its block menu, a code block with its language list, the image toolbar and the empty image's panel, and the callout's icon picker. The `edytor-notion` class applies the imported [Notion theme](/docs/customization/styling#notion-theme). Take only the plugins you need: a plugin left out takes its chrome with it, and the editor still edits.

To change the words, call `setWords` ([Localization](/docs/customization/localization)). To draw one surface your own way instead, give its factory your snippet (`slashMenu({ menu })`): see [Menus and handles](/docs/customization/menus). To own all of the markup, start from the starter's source in the repository, [`src/lib/starter/chrome`](https://github.com/beynar/edytor/tree/master/src/lib/starter/chrome), and pass your copy's snippets to the package's factories.
