An inline block, or atom, is a non-editable element inside a block's text: a mention, a date chip, a footnote marker. It sits between text runs, moves with the text, and is selected, copied and deleted as one unit. Atoms live in a plugin's `inlineBlocks` map.

In the document an atom is a part of the block's content, with a type and data:

```json
{
	"type": "paragraph",
	"content": [{ "text": "Thanks " }, { "type": "mention", "data": { "label": "Ada" } }, { "text": "!" }]
}
```

Content always starts and ends with text, and text runs separate atoms; the editor inserts empty text runs where needed.

The snippet receives `{ block }`, a view of the atom:

<TypeTable
  type={{
    id: { type: "string", description: "The atom's id." },
    type: { type: "string", description: "The atom's type." },

    selected: { type: "boolean", description: "The atom is selected. Reactive. Always false for a suggested atom." },

/>

The core wraps the snippet in `<span data-edytor-inline-block="<type>" data-edytor-id="<id>" contenteditable="false">`. In HTML copied to the clipboard an atom is its `html` form, by default an empty span with the same `data-edytor-inline-block` attribute; content pasted into an Edytor keeps its atoms through the editor's own clipboard format, and HTML from elsewhere becomes atoms where a `parse` hook claims an element (the [equation](/docs/plugins/equation) plugin's inline equation reads MathML this way).

## A mention atom

For people mentions, use the [mention plugin](/docs/plugins/mention): `@` opens a menu of your app's people and inserts a `mention` atom. Your own atom is a definition and a way to insert it, usually a [trigger](/docs/plugins/input-rules#triggers). This plugin inserts a date chip from a menu that `@` opens:

```svelte title="DatePlugin.svelte" check
<script module lang="ts">
	import type { InlineBlockSnippetPayload, Plugin, Trigger } from 'edytor';

	const days: Trigger<string> = {
		char: '@',
		name: 'Dates',
		items: (query) => ['today', 'tomorrow'].filter((day) => day.startsWith(query)),
		// `from` is where the `@` was: the atom goes there, the caret after it.
		onPick: (day, { block, from, caret }) => {
			const after = block.addInlineBlock({ offset: from, block: { type: 'date', data: { day } } });
			if (after) caret(from + 1);
			return !!after;
		}
	};

	export const datePlugin: Plugin = () => ({
		inlineBlocks: {
			date: { snippet: date, plain: (data) => `@${data?.day ?? ''}` }
		},
		triggers: [days]
	});
</script>

{#snippet date({ block }: InlineBlockSnippetPayload)}
	<span class="date" class:selected={block.selected}>@{block.data.day}</span>
{/snippet}
```

```css
.date {
	padding: 0 3px;
	border-radius: 3px;
	background: #eef3ff;
	color: #2f5bd3;
}
.date.selected {
	outline: 2px solid #2f5bd3;
}
```

## Inserting, updating and removing atoms

Insert an atom with `addInlineBlock` on the block, at an offset of its content (block offsets, an atom counting 1; the caret's):

```ts title="insertMention.ts" check
const caret = edytor.selection.caret; // { block, offset }, or null when the selection is not a caret
if (caret) {
	const { block, offset } = caret;
	const after = block.addInlineBlock({ offset, block: { type: 'mention', data: { label: 'Ada' } } });
	// after is the text segment right after the atom: put the caret there.
	if (after) edytor.selection.setCaret({ block, offset: offset + 1 });
}
```

It is an `addInlineBlock` operation, visible to plugins. An atom's id is generated when you leave `id` out.

An atom's handle is an `InlineBlock`: `atom.data` is its data as a live proxy (`atom.data.name = 'Ada'` writes one property), `atom.setData(data)` replaces it (both a `patchData` operation on its block with `atom` set, visible to plugins and refused in a readonly view; see [Properties](/docs/concepts/properties)), `atom.parent` is its block and `atom.index` its position in `block.content`. Remove it with a `removeInlineBlock` operation on its block:

```ts title="removeMention.ts" check
const atom = block.content.find((part) => part.id === 'mention-1');
if (atom) block.removeInlineBlock({ index: atom.index });
```

Users select an atom with the arrow keys or a click; <kbd>Backspace</kbd> or <kbd>Delete</kbd> removes a selected atom, and typing replaces it.

Atoms can also be part of the initial value, as in the JSON at the top of this page.
