Edytor ships as one npm package, `edytor`. It contains the `<Edytor>` component, the bundled plugins, the collaborative document API and its CRDT engine, and a Cloudflare Durable Object room.

:::warning[New release]
Edytor `1.0.0` is its first stable release: its API follows semantic versioning, and every change is listed in the changelog. It has no production track record yet; read the [limitations](/docs/reference/limitations).

These docs describe that release. `edytor@0.0.11`, which npm installed without a tag before it, predates it and uses a different API; the [changelog](/docs/reference/migration) lists every change.
:::

## Requirements

- **Svelte 5.** `svelte` is a peer dependency (`^5.0.0`). The editor uses runes and snippets, so Svelte 4 is not supported.
- **A Svelte-aware bundler.** The root entry ships `.svelte` files. SvelteKit, or Vite with `@sveltejs/vite-plugin-svelte`, compiles them with its default config: nothing to add to `vite.config`.
- **Node.js 22 or later** (the package's `engines` field).
- **A Baseline 2024 browser.** Chrome and Edge 120, Firefox 125, Safari 17.4 or Chrome on Android 120, or later; the current versions are tested. Real phones and their keyboards are not tested yet. See [Platform support](/docs/reference/platform-support).

## Install

Edytor is on npm under `latest`:

```package-install
pnpm add edytor
```

Each release is published from CI with npm provenance. The pre-releases before it are under the `next` tag.

Earlier installs by URL keep working: this site still serves every pre-release tarball it hosted, each at its versioned URL, and the bytes under a URL never change, so a lockfile's URL and integrity hash stay valid. Switch to `edytor` when you upgrade.

If your project does not have Svelte yet, add it too:

```package-install
npm i -D svelte
```

Do not install `yjs` for Edytor. The collaboration engine (a fork of Yjs v14) is vendored inside the package and is available as [`edytor/crdt`](/docs/getting-started/entry-points). The `yjs` package on npm is v13, which cannot exchange updates with v14.

The package pulls in a few runtime dependencies on its own: Atlassian's Pragmatic Drag and Drop (block handles), TanStack Highlight (code block highlighting) and `lib0`.
