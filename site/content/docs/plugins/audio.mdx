`createAudioPlugin()` adds Notion's audio block: an "Embed audio" panel (your `empty` snippet, `createMediaEmptyPlugin({ empty })`) until the block has a source, then the browser's player (`<audio controls>`), with an editable caption. It is not a default plugin: list it.

```svelte title="Editor.svelte" check
<script lang="ts">
	import { Edytor, createAudioPlugin } from 'edytor';
</script>

<Edytor plugins={[createAudioPlugin()]} />
```

A [slash menu](/docs/plugins/slash-menu) then lists "Audio" under `Media`. Without the uploads plugin (`createUploadsPlugin({ upload })`), audio files are linked only.

## Try it

Click the empty audio block ("Embed audio") to link a sound or pick one from your computer (it plays from this tab only). The editor is local to this page: a reload resets it.

## Customize

The empty slot is your `empty` snippet (`createMediaEmptyPlugin({ empty })`), so it can look like anything. Here, a dashed drop zone with a link field and an Upload button.

```svelte title="AudioEditor.svelte" check
<script lang="ts">
	import {
		Edytor,
		createAudioPlugin,
		createMediaEmptyPlugin,
		createUploadsPlugin,
		type JSONDoc,
		type MediaEmptyController,
		type Plugin
	} from 'edytor';

	// The page's document and the rest of your editor's plugins.
	let { value, plugins = [] }: { value?: JSONDoc; plugins?: Plugin[] } = $props();

	// An app would upload to its storage; this keeps the file in the tab.
	const uploads = createUploadsPlugin({
		upload: async (file, report) => {
			report.progress(1);
			return URL.createObjectURL(file);
		}
	});

	// The empty slot of every media block, drawn by the snippet below.
	const empty = createMediaEmptyPlugin({ empty: slot });
	const audio = createAudioPlugin();
</script>

<!-- A drop zone: one big target, the link field below it. -->
{#snippet slot(slot: MediaEmptyController)}
	{#if slot.pending?.status === 'uploading'}
		<div class="zone" role="status">
			<progress value={slot.pending.progress ?? undefined} max="1"></progress>
			Uploading…
		</div>
	{:else if slot.readonly}
		<div class="zone">{slot.icon} Nothing here yet</div>
	{:else}
		<div class="zone">
			<span class="icon" aria-hidden="true">{slot.icon}</span>
			<strong>Add a sound</strong>
			<div class="row">
				<input
					placeholder="https://…/clip.mp3"
					aria-label="Audio link"
					bind:value={slot.draft}
					{@attach slot.field}
				/>
				<button type="button" onclick={() => slot.embed()}>Link</button>
				{#if slot.canUpload}
					<label class="pick">
						Upload
						<input
							type="file"
							accept={slot.accept}
							hidden
							onchange={(event) => {
								const picked = event.currentTarget.files?.[0];
								if (picked) void slot.upload(picked);
							}}
						/>
					</label>
				{/if}
			</div>
			{#if slot.failed}
				<small>That did not work. Try another file or link.</small>
			{/if}
		</div>
	{/if}
{/snippet}

<Edytor {value} plugins={[audio, empty, uploads, ...plugins]} aria-label="Audio demo" />
```

## Options

`createAudioPlugin()` takes no options. The empty block is drawn by the view's media empty plugin ([Menus and handles](/docs/customization/menus#empty-image-and-media-blocks)). With the uploads plugin listed, the empty block has an Upload (`accept="audio/*"`) and pasted and dropped audio files become audio blocks ([Pasted and dropped files](/docs/editor/clipboard#pasted-and-dropped-files)); the answer is stored only when the block is still there, of its kind and without a source: a source a collaborator set while the upload ran stays.

## The kind

| Kind    | Element  | Data              | Preset                                                     |
| ------- | -------- | ----------------- | ---------------------------------------------------------- |
| `audio` | `figure` | `{ src: string }` | Audio (🎵, group `Media`, keywords `sound`, `music`, `mp3`) |

A source is accepted only when it is an `http:`/`https:` URL with a host or a `blob:` URL of one (`safeMediaSrc`), never `data:` or a script URL; any other stored value shows no player. The player has `controls` and `preload="metadata"`.

The block is void like the [image](/docs/plugins/image), and its only text is the caption. The command id is `block.audio`. Its role is in `defaultSemantics`. In a readonly view the empty block is a passive placeholder.

## Clipboard

- Copying exports `<figure><audio src="…" controls></audio><figcaption>caption</figcaption></figure>`.
- Pasting HTML imports an `audio` with a safe `src`, or a `source` child with one (bare, or in a `figure` whose `figcaption` becomes the caption). Without the plugin, a pasted `audio` is dropped.

## Styling

| Selector                     | Matches                     |
| ---------------------------- | --------------------------- |
| `[data-edytor-type='audio']` | The `figure`                |
| `[data-edytor-audio]`        | The wrapper of the `audio`  |

The empty state uses the shared `media` selectors (see [Embed](/docs/plugins/embed#styling)).
