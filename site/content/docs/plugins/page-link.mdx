`createPageLinkPlugin` brings Notion's `[[` page links. Typing `[[` opens a menu of the pages your app's `search(query)` answers; the text typed after it filters them. Picking one replaces `[[query` with a `pageLink` atom, a link to the page, and puts the caret after it. The menu is your `menu` snippet, as the [mention](/docs/plugins/mention)'s is.

```svelte title="Editor.svelte" check
<script lang="ts">
	import { Edytor, createPageLinkPlugin, type PageLinkItem } from 'edytor';

	const search = async (query: string) => {
		const response = await fetch(`/api/pages?q=${encodeURIComponent(query)}`);
		return (await response.json()) as PageLinkItem[];
	};

	const pageLinks = createPageLinkPlugin({ search, href: (page) => `/pages/${page.id}` });
</script>

<Edytor plugins={[pageLinks]} />
```

### Pasted references

`fromPaste` turns a pasted text your app recognizes into a page link: your own URL for a page, or any text you can read as one. It answers the page, or `null` to leave the paste alone.

```svelte title="PastedLinks.svelte" check
<script lang="ts">
	import { Edytor, createPageLinkPlugin, type PageLinkItem } from 'edytor';

	const pages: PageLinkItem[] = [{ id: '123', title: 'Roadmap', icon: '🗺️' }];
	const search = (query: string) => pages.filter((page) => page.title.includes(query));

	// https://app.example.com/p/123 is page 123.
	const fromPaste = (text: string) => {
		const id = /^https:\/\/app\.example\.com\/p\/(\w+)$/.exec(text)?.[1];
		return pages.find((page) => page.id === id) ?? null;
	};

	const pageLinks = createPageLinkPlugin({ search, fromPaste });
</script>

<Edytor plugins={[pageLinks]} />
```

It is asked for a paste at a caret whose plain text is one item: trimmed, on one line. A paste of several lines, or over a selection, is left alone. A page answered at once replaces the pasted text with the page link, an undo step of its own after the paste, so one undo gives the plain text back. The answer wins over the rich text link and the URL menu of an empty line, whatever the order you list the plugins in: a URL `fromPaste` recognizes becomes the page link, any other is linked (or offered as an embed) as before. A promise lets the paste land as it would without the option, linked or not, and swaps it for the page link when it answers, if the text is still there; undo gives back what the paste wrote. A readonly view pastes nothing.

It is not a default plugin: list it in `plugins`, in every view of a document that holds page links.

## Customize

This one draws the menu as a grid of tiles, each with the page's icon large above its title, through the `menu` snippet.

```svelte title="PageLinkEditor.svelte" check
<script lang="ts">
	import {
		Edytor,
		createPageLinkPlugin,
		type JSONDoc,
		type PageLinkItem,
		type Plugin,
		type TriggerMenuController
	} from 'edytor';

	// The page's document and the rest of your editor's plugins.
	let { value, plugins = [] }: { value?: JSONDoc; plugins?: Plugin[] } = $props();

	const pages: PageLinkItem[] = [
		{ id: 'p1', title: 'Roadmap', icon: '🗺️' },
		{ id: 'p2', title: 'Meeting notes', icon: '📝' },
		{ id: 'p3', title: 'Design system', icon: '🎨' },
		{ id: 'p4', title: 'Release checklist', icon: '✅' },
		{ id: 'p5', title: 'Onboarding guide', icon: '👋' }
	];

	// Pages as tiles in a grid under the caret.
	const pageLinks = createPageLinkPlugin({
		search: (query) =>
			pages.filter((page) => page.title.toLowerCase().includes(query.trim().toLowerCase())),
		menu
	});
</script>

<!-- A tile grid: the page's icon large, its title underneath. -->
{#snippet menu(menu: TriggerMenuController<PageLinkItem>)}
	<div class="tiles" onmousedown={(event) => event.preventDefault()} role="presentation">
		<div class="title">Link to a page</div>
		<div class="grid" aria-label="Pages" {@attach menu.popup}>
			{#each menu.items as page, index (page.id)}
				<!-- svelte-ignore a11y_click_events_have_key_events, a11y_no_static_element_interactions -->
				<div
					class="tile"
					data-selected={menu.index === index}
					onmousemove={() => (menu.index = index)}
					onclick={() => void menu.pick(page)}
					{@attach menu.option(index)}
				>
					<span class="icon" aria-hidden="true">{page.icon}</span>
					<span class="name">{page.title}</span>
				</div>
			{:else}
				<div class="empty" role="presentation">
					{menu.loading ? 'Searching…' : 'No page by that name'}
				</div>
			{/each}
		</div>
	</div>
{/snippet}

<Edytor {value} plugins={[pageLinks, ...plugins]} aria-label="Page link demo" />
```

## Options

A `PageLinkItem` is `{ id, title, href?, icon? }`: `id` is the page's id in your app, `title` the text shown, `href` where the link goes (absolute, or relative to your app) and `icon` a short icon such as an emoji (default 📄).

## The page link atom

A page link is an inline block of type `pageLink` whose data is `{ id, title, href?, icon? }`:

```json
{ "type": "pageLink", "data": { "id": "p1", "title": "Roadmap", "href": "/pages/p1", "icon": "🗺️" } }
```

It renders an `<a class="edytor-page-link" data-edytor-page-link href="…">` holding the icon (`.icon`) and the title (`.title`), with `data-selected="true"` while the atom is selected (the [Notion theme](/docs/customization/styling#notion-theme) draws the underlined title and the selection), and copies as plain text as its title. The `href` goes through the link sanitizer when it is stored and when it is rendered: a `javascript:` or other script URL is dropped, and the atom renders without one. The title is the one stored when it was picked: to show a page's current title, render your own snippet (`pageLinkInlineBlock`) that looks it up by `data.id`.

## Behavior

The menu is a [trigger](/docs/plugins/input-rules#triggers) of two characters: it opens when the second `[` completes `[[` at the start of a text or after whitespace. A single `[` (`[] ` for a to-do with the [markdown shortcuts](/docs/plugins/markdown-shortcuts)) opens nothing. <kbd>↑</kbd>/<kbd>↓</kbd> move the highlight, <kbd>Enter</kbd> or a click picks, <kbd>Escape</kbd> closes it and keeps the text. The pick is one undo step; a refusal keeps `[[query`. The menu's listbox is named "Pages".

For people, see [Mention](/docs/plugins/mention).
