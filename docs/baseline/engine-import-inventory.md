## 5. Ecosystem package usage notes

- `y-indexeddb@9.0.12` is a declared dependency but **not imported** — `src/lib/localProvider.ts` re-implements it (lib0 idb + BroadcastChannel sync + awareness relay). The v14 migration must treat `localProvider.ts` as the persistence contract, not upstream y-indexeddb.
- `y-websocket` used only through `createWebsocketSync` (`providers.ts`); `WebsocketProvider` is re-exported.
- `y-protocols` `Awareness` is the shared awareness instance constructor-injected into `Edytor` (`edytor.svelte.ts:207`).
- `RelativePosition` plumbing (`createRelativePositionFromTypeIndex` with assoc `-1`, `createAbsolutePositionFromRelativePosition`, `relativePositionToJSON`, `createRelativePositionFromJSON`) is the selection-preservation mechanism across local text edits and remote updates — identity-critical for v14.
